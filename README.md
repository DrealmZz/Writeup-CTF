# CTF Write-ups

A collection of write-ups for Capture The Flag (CTF) challenges I have completed.

## Repository Structure

Each challenge directory contains:

```
challenge-name/
├── README.md                  # Write-up
├── images/                    # Solution screenshots
└── files/                     # Challenge files (source code, binaries, etc.)
```

## Write-up Format

Each write-up follows this standard format:

1. **Challenge Description** – Challenge description and provided attachments.
2. **Solution** – Step-by-step walk-through.
3. **Flag** – The final flag value.

Additional notes or alternative methods may be included for complex challenges.
